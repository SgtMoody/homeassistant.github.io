Datenschutzerklärung

Diese Anwendung ist eine private Anbindung zwischen einer selbst betriebenen Home-Assistant-Installation und dem Google-Kalender ihres Betreibers. Sie wird nur vom Betreiber selbst genutzt.

Welche Daten verarbeitet werden

Mit Zustimmung des Nutzers greift Home Assistant über die Google Calendar API auf die Kalender des eigenen Google-Kontos zu, um Termine anzuzeigen und auf Wunsch anzulegen oder zu ändern.

Wo die Daten gespeichert werden

Die Kalenderdaten werden ausschließlich in der privaten Home-Assistant-Installation des Betreibers im eigenen Heimnetz verarbeitet. Es gibt keinen Server dieser Anwendung, der Daten sammelt.

Weitergabe

Daten werden nicht an Dritte weitergegeben, nicht verkauft und nicht für Werbung genutzt. Die Nutzung von Daten aus Google-APIs entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Widerruf

Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden.
